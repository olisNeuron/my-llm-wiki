# Virtual Memory（虚拟存储器）

一句话核心：**虚拟存储器是硬件（MMU、异常）、操作系统、主存与磁盘协同提供的抽象：把主存当作磁盘地址空间的高速缓存，给每个进程一致的私有地址空间，并保护其不被破坏**。

## 三大能力

1. 把主存看作磁盘上地址空间的**缓存**，只保留活动区域，按需换入换出，高效利用内存；
2. 为每个进程提供**一致、私有的地址空间**，简化存储管理；
3. **保护**每个进程的地址空间不被其他进程破坏。

## VM 作为缓存

- 虚拟页 VP 与物理页 PP（页帧）大小固定（典型 4KB~2MB）；已分配页分**缓存的**与**未缓存的**。
- DRAM 缓存特点（由巨大不命中处罚驱动）：页大、**全相联**（任何虚拟页可放任何物理页）、替换算法复杂、总是**写回**。
- **页表**（PTE 数组）把虚拟页映射到物理页；操作系统维护内容，MMU 硬件负责翻译。
- **页命中**：PTE 显示页已缓存；**缺页**（page fault）：触发内核缺页处理程序，换入页面（交换/页面调度）。
- **工作集**（常驻集）：局部性保证程序在某一时刻只活跃于少量页；若工作集超过物理内存，就发生**颠簸**（thrashing），页面不断换进换出。

## 管理、保护与翻译

- 每个进程有独立页表 = 独立虚拟地址空间；多个虚拟页可映射同一共享物理页。
- 地址翻译硬件（MMU）+ 页表实现虚拟→物理；**TLB**（页表项的小缓存，高相联度）加速翻译；大地址空间用**多级页表**节省内存。
- 页表项带访问权限位，实现读/写/执行保护和内核/用户隔离。

## 存储器映射与动态分配

- **存储器映射**：把虚拟内存区域关联到磁盘对象（普通文件或匿名文件）；共享对象多进程共享，私有对象用**写时拷贝（copy-on-write）** 实现。
- 动态分配器维护**堆**：显式分配器（malloc/free）要应用自己释放；隐式分配器即**垃圾收集器**，自动回收。
- **碎片**：内部碎片（块比有效载荷大）和外部碎片（空闲总量够但无单个足够大的块）。

## 常见内存错误

间接引用坏指针、读未初始化内存、栈缓冲区溢出、误用指针运算、引用已释放堆块、内存泄漏等。

# 自学路线与公开课

知乎收藏里关于"计算机自学"的内容高度收敛：**主流共识是跟着名校公开课走一条相对固定的路线，而不是在国内课堂/培训班里打转**。公开课的最大价值在于：教材与讲义开源、作业带自动评测（autograder）、lab 设计用心，且对自学和求职都直接有用。

## 一条被反复验证的主线

- **入门**：CS50（零基础）→ **CS61A**（Berkeley，Python 版 SICP：抽象、递归、高阶函数）→ **CS61B**（Java：数据结构、算法、面向对象）→ **CSAPP / CMU 15-213**（计算机系统）→ **操作系统**（MIT 6.S081 或 UCB CS162）→ 数据库（CMU 15-445）等。这也是 TeachYourselfCS 指南推荐的顺序。
- 多篇收藏把 CS61A 称为"最好的 CS 入门课"，强调它教的不是语法而是**用抽象管理复杂性**；CS61B 是承上启下的数据结构课，lab 用 autograder 自动判分。
- 实操准备（CS61A 自学前）：浏览器翻译插件、Git/Git Bash、课程代码系统的 autograder 配置；CS61B 的 Autograder 需要下载 GitHub Desktop 并按 skeleton 配置。

## 课程难度与时间预估

- **CS61B**：认真做完全部 lab/project 大约需要 2–4 个月；有博主估算约 300 小时，并指出 csdiy 网站上"预计 60 小时"严重低估——它更像给顶尖学校学生看的目录，而不是人手把手的路线图。
- **6.S081**：lab 是 xv6 的独立小分支，hint 详细，按 hint 走难度可控；前置需要一定 C 语言经验和 OS 基础（可先读 ostep）。
- **CS162 vs 6.S081**：6.S081 讲师阵容强（Russ Cox 等）、xv6 代码和书漂亮；CS162 的 PPT 和视频质量更稳定。
- **15-213/CSAPP**：覆盖面广（数据表示、汇编、处理器、内存、链接、网络、并发），认真学完约需一个学期；蒋炎岩（南大）的 OS 课因"上课耽误学习"式的高强度自学要求而出名。

## 为什么值得花时间

- 公开课 lab 对应届生面试帮助大：教材即讲义、讲师即作者、全程可在线免费获取。
- 名校公开课程评价项目（胡津铭等组织）把这些资源聚合成目录，方便按需挑选。
- 有博主记录"和 Codex 互动学习 CSAPP"的完整流程：让 AI 辅助讲解、按小节推进——AI 可以当助教，但体系仍在。

## 进阶方向

- ML/DL 系统研究方向的知识结构：从经典深度学习（AlexNet、GNN）到框架、分布式系统、安全等子方向，UCB AI-Sys 课程是很好的起点。
- 若只喜欢算法不喜工程：读博/研究路线更契合（陈越姥姥观点）。

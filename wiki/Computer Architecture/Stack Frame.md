# Stack Frame（程序的机器级表示与栈帧）

一句话核心：**高级语言的过程调用、局部变量和控制流，在机器层面由指令序列和运行时栈实现**。

## 机器级视角

- **ISA（指令集体系结构）** 定义处理器状态、指令格式及每条指令对状态的影响；机器级程序看到的是虚拟地址下的巨大字节数组。
- 对程序员可见的处理器状态：程序计数器 PC、整数寄存器、条件码寄存器（记录最近算术/逻辑操作属性）、浮点寄存器。
- 程序存储器包含：可执行代码、操作系统信息、运行时栈、用户分配的存储块。

## 数据与运算

- 操作数三种类型：**立即数**（常数）、**寄存器**、**存储器引用**（按计算出的地址访问）。
- 常见指令：数据传送（mov）、加载有效地址（lea，只算地址不访存）、一元/二元操作、移位。
- 控制：条件码 + 条件跳转实现分支；循环由条件测试与跳转组合；**switch 用跳转表**，执行时间与分支数量无关。

## 过程与栈帧

- 过程调用靠**程序栈**：传递参数、保存返回地址、保存寄存器、分配局部存储。
- 单个过程占用的栈区域叫**栈帧**（stack frame）。
- 寄存器惯例：%eax/%edx/%ecx 是**调用者保存**（被调者可以覆盖）；%ebx/%esi/%edi 是**被调用者保存**（调用者依赖其值不变）。

## 数据布局与指针

- 数组：连续存储，指针运算按元素类型大小伸缩（p+i 的地址是 xp + L×i）。
- 结构体：字段存放在连续区域，编译器用字段偏移生成访问指令。
- 联合：多个字段共享同一块存储。
- **对齐**：要求某些类型的地址是 2/4/8 的倍数，简化硬件设计。
- 指针要点：每个指针有类型和值（NULL 表示不指向任何地方）；& 取地址、* 间接引用；数组名≈不能修改的指针；类型转换只改类型不改值（但会改变指针运算伸缩）；可以有函数指针。

## 缓冲区溢出

C 对数组**不做边界检查**，而局部变量和返回地址同在栈上——越界写会破坏状态信息，ret 时程序就可能跳转到攻击者覆盖的地址，执行攻击代码。这是最常见的系统入侵途径之一。

# Cache Locality（存储器层次结构与缓存局部性）

一句话核心：**程序倾向于反复访问同一批或相邻的数据（局部性），缓存正是利用这一点弥合 CPU 与主存的速度差距**。

## 存储技术

- **SRAM**：快而贵，用作高速缓存（L1/L2/L3，片上或片下）。
- **DRAM**：慢而便宜，用作主存和图形帧缓冲。
- **磁盘**：访问时间 = 寻道时间 + 旋转时间 + 传送时间；**SSD** 基于闪存。
- 趋势：存储技术各有价格/性能折中；DRAM 和磁盘的访问延迟比 CPU 时钟周期增长慢得多，差距在拉大。

## 局部性原理

- **时间局部性**：最近访问过的数据很可能再次访问（如循环中的变量）。
- **空间局部性**：邻近的数据很可能被一起访问；引用步长越小，空间局部性越好。
- 取指也有局部性：循环体越小、迭代越多，局部性越好。

## 存储层次与缓存

- 层次结构每一层都是下一层的**缓存**，数据以**块**为单位在相邻层间搬运。
- **缓存命中**：数据已在当前层；**缓存不命中**：需要从下一层取块，可能驱逐现有块（牺牲块），替换策略如 LRU。
- 冷缓存（空缓存）导致的**强制不命中**（compulsory/cold miss）。

## 高速缓存的组织

- 按"组"组织，每行有 tag 等元数据；三种映射：
  - **直接映射**：每组只有一行（E=1），简单但冲突不命中多；
  - **组相联**：每组多行，折中；
  - **全相联**：所有行在一个组，最灵活。
- 写策略：
  - 命中时：**直写**（立即写回主存，简单但总线事务多）vs **写回**（延迟写，用脏位 dirty bit 标记，减少总线事务）；
  - 不命中时：**写分配**（先加载块再更新）vs **非写分配**（直接写主存）。
- 分类：指令缓存（i-cache）、数据缓存（d-cache）、统一缓存。
- 性能指标：命中率/不命中率、命中时间、不命中处罚；调优参数：缓存大小、块大小、相联度、写策略。

## 缓存友好代码

1. 让最常见的情况运行得快；
2. 每个循环内部让不命中数量小（好好利用时间与空间局部性）。

# CSAPP 核心思想

《深入理解计算机系统》（CSAPP）从程序员视角串起整个计算机系统：**所有信息都是"位 + 上下文"，系统由硬件、操作系统、网络层层抽象而成**。理解这些抽象如何工作，是写出正确、高效、安全程序的基础。

## 全书主线

- **信息 = 位 + 上下文**：程序、数据、文本在机器里都只是一串比特；区分不同数据对象靠的是解释它的上下文。
- **程序的生命周期**：预处理 → 编译 → 汇编 → 链接 → 加载执行。每个阶段都值得理解：优化性能要看汇编，链接错误要从链接器找，缓冲区溢出等安全漏洞源于对栈和内存布局的无知。
- **硬件五大部件**：总线（部件间传字节）、I/O 设备（对外联系）、主存（运行时的程序与数据）、处理器（解释并执行指令），加上高速缓存作为 CPU 与主存之间的桥梁。
- **存储层次结构**：寄存器 → 高速缓存 → 主存 → 磁盘，越往上越快、越小、越贵。**缓存**（用快的存慢的）是贯穿全书的核心思想。
- **操作系统三大抽象**：
  - 进程：对运行中程序的抽象，通过上下文切换让多个进程看似独占硬件；
  - 虚拟存储器：给每个进程"独占主存"的假象；
  - 文件：把一切 I/O 设备统一为字节序列。
- **网络**：跨系统通信，本质上是系统级 I/O 的延伸。

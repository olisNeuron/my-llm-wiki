## 工具 1：Σ 求和

```
Σ_{i=1}^{n} i     读作"i 从 1 加到 n，把每个 i 累加"
```

**只需背 3 个公式：**

| 公式 | 结果 | 6.006 里出现在 |
| --- | --- | --- |
| Σ_{i=1}^{n} 1 | n | 每层 O(1)、共 n 层 |
| Σ_{i=1}^{n} i | n(n+1)/2 | **选择 / 插入排序** |
| Σ_{i=0}^{n} 2^i | 2^(n+1) − 1 | 完全二叉树、递归分支 |

**用途：把"每一层的工作量"加起来。** 以选择排序为例：

```
第 k 层的工作量 = Θ(k)        →   Θ(n), Θ(n−1), …, Θ(1)
总工作量 = Σ_{k=1}^{n} Θ(k) = Θ(n(n+1)/2) = Θ(n²)
```

⚠️ **最容易混的一点**：

| 情形 | 规则 | 例子 |
| --- | --- | --- |
| 常数个项相加 | 取最大的 | Θ(n−1) + Θ(n) = **Θ(n)** |
| n 个项求和 | 必须求和，不能"取最大" | Σ_{k=1}^{n} Θ(k) = **Θ(n²)** |

判断标准只有一句：**项数是常数，还是跟着 n 一起变？**

> n² 的来源是"**n 项**"和"**每项约 n**"相乘。少写了省略号，就等于把 n 项偷偷变成了 2 项。

## 工具 2：归纳法

**两段式模板：**

```
命题 P(n)：关于 n 的某个断言
① Base case     ：证 P(1)（或 P(0)）成立
② Inductive step：假设 P(n−1) 成立（归纳假设），据此证明 P(n) 成立
∴ 对所有 n ≥ 1，P(n) 成立
```

**它和递归代码是同一件事：**

| 递归代码 | 归纳法 |
| --- | --- |
| base case（`if i == 0: return …`） | ① Base case |
| 递归调用 `f(A, i-1)` | ② 归纳假设（"假设子问题已解决"） |
| 用返回值拼出当前答案 | ② 归纳步的推导 |

这就是为什么"假设 `f(A, i-1)` 已经对了"是合法的——**它不是偷懒，是归纳假设**。

**递推式 = 归纳法的公式版**：把归纳步里"规模 n 与规模 n−1 的关系"写成等式，就得到 `T(n) = T(n−1) + f(n)`。

**强归纳**（MCS 5.2）：归纳假设从"P(n−1)"加强为"P(1)…P(n−1) 全部成立"。分治算法需要它——归并排序要假设两个一半都已排好。

## 工具 3：渐近记号

**正式定义（MCS 14.7.9）：**

> f = O(g) 当且仅当**存在**常数 c ≥ 0 和 x₀，使得**对所有** x ≥ x₀，都有 |f(x)| ≤ c · g(x)。

看着吓人，翻成人话：

| 定义里的部分 | 人话 |
| --- | --- |
| **存在** c | "有个常数倍率，多大都行" |
| **存在** x₀ | "从某个规模开始算，小规模不管" |
| **对所有** x ≥ x₀ | "此后一直成立" |

**→ f = O(g) 的意思就是："从某个规模往后，f 最多是 g 的某个常数倍。"**

💡 **关键领悟**：[[Asymptotic Analysis]] 里那四条简化规则（只看最坏、去掉低阶项、去掉常数）**不是工程惯例，而是这个定义里 c 和 x₀ 两个自由度直接推出来的**：

- **c 随便选** → 常数系数可以扔（100n² 和 n² 都是 O(n²)）
- **x₀ 随便选** → 低阶项可以扔（n² + 100n + 10 = O(n²)：n 足够大时 100n 被 n² 淹没）

**四个记号的区别：**

| 记号 | 含义 | 直觉 |
| --- | --- | --- |
| O(g) | 上界（≤，可差常数倍） | f 长得**不快于** g |
| Ω(g) | 下界（≥） | f 长得**不慢于** g |
| Θ(g) | 紧界（O 且 Ω） | f 和 g **一样快** |
| o(g) | 严格更慢（lim f/g = 0） | g **完全碾压** f |

⚠️ **O 不等于"最坏情况"**。最坏情况本身也能用 Θ 精确描述；O 只是"上界"。这是最常见的混淆。

## 工具 4：对数运算

| 规则 | 说明 |
| --- | --- |
| log(ab) = log a + log b | 乘法变加法 |
| log(a^k) = k · log a | 指数搬下来 |
| log_b n = log n / log b | 分母是常数 → **底数无关**，Θ(log₂ n) = Θ(log n) |
| log n = o(n^ε)，对任意 ε > 0 | log 比任何正幂次都慢（MCS Lemma 14.7.3） |

**为什么重要**：递归树的高度经常是 log n——每次规模减半，2^h = n，所以 h = log₂ n。merge sort 的 Θ(n log n) 里那个 log 就来自这里。

## 工具 5：递归树 + Master Theorem

**递归树 = 求和的可视化**，两步：

1. **画树**：每次递归调用画一个子节点
2. **算总和**：Σ(每层工作量)，或 节点数 × 每节点工作量

**五种基本形状：**

| 递推式 | 树形 | 层数 | 每层工作量 | 结果 |
| --- | --- | --- | --- | --- |
| T(n) = T(n−1) + Θ(1) | 链 | n | Θ(1) | **Θ(n)** |
| T(n) = T(n−1) + Θ(n) | 链 | n | Θ(k)（第 k 层） | **Θ(n²)** |
| T(n) = 2T(n−1) + Θ(1) | 二叉树 | n | 2^k（第 k 层） | **Θ(2ⁿ)** |
| T(n) = T(n/2) + Θ(1) | 链 | log n | Θ(1) | **Θ(log n)** |
| T(n) = 2T(n/2) + Θ(n) | 平衡二叉树 | log n | Θ(n) | **Θ(n log n)** |

**一句话记住**：链式递推 → 层数 **n**；分治递推 → 层数 **log n**。

> **分治比链式快的全部秘密，就是把层数从 n 压到了 log n。**

**Master Theorem（6.006 用这个版本）**：对 `T(n) = a·T(n/b) + Θ(n^c)`，比较 c 和 log_b a：

| 情况 | 条件 | 结果 | 直觉 |
| --- | --- | --- | --- |
| 1 | c < log_b a | Θ(n^(log_b a)) | 叶子（底层）主导 |
| 2 | c = log_b a | Θ(n^c · log n) | 每层工作量均衡 |
| 3 | c > log_b a | Θ(n^c) | 根（顶层）主导 |

例：归并排序 a=2, b=2, c=1，log₂2 = 1 = c → 情况 2 → Θ(n log n)。

⚠️ **前提**：规模必须按**倍数**缩小（n → n/b）。看到 `T(n−1)` 就**不能**用 Master Theorem，只能画链/用代入法——这是最常见的误用。

⚠️ **MCS 22.4 用的是更一般的 Akra-Bazzi 公式（带积分），远高于 6.006 的要求。别被吓到**——6.006 只需要上面这个三情况版本（见 R03 第 5–6 页）。

## 常见误区

| 误区 | 正确做法 |
| --- | --- |
| 把 `Θ(n−1) + Θ(n)` 当成 n 项求和 | 常数项相加取最大 = Θ(n)；n 项才要 Σ |
| 链式递推写成"层数 × 每层最大" | 第 k 层工作量不同，必须**求和**（或"层数 × 平均"） |
| 对 T(n−1) 型递推用 Master Theorem | 只能用递归树 / 代入法 |
| 把 O 当成"最坏情况" | O 是上界；最坏情况也能用 Θ 精确描述 |
| 忘了算辅助函数的成本 | 一行 `prefix_max(A, i)` 实际是 Θ(i)，不是 O(1) |
| 只写结果、不写树 | 考试要求展示递归树和求和过程 |
